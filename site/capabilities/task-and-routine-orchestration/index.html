WORKFLOW DIAGRAM

How Tempo works.

Follow the numbered sequence. If evidence or access is missing, resolve it before advancing. Review the result before taking an external action.

  1. INPUT

    Trigger conditions · authorized systems · desired outcome · owner

  2. STEP 01

    Define triggers and cadence

  3. STEP 02

    Enumerate actions and idempotency boundaries

  4. STEP 03

    Add human approvals for external writes

  5. STEP 04

    Configure failure and retry policy

  6. STEP 05

    Record run history and disable controls

  7. REVIEW

    Do not claim a routine is scheduled unless a scheduler was configured

  8. OUTPUT

    Routine definition · execution plan · monitoring checklist

Approval gate → Review the deliverables. If changes are needed, return to the relevant step. Publish, send, deploy or change external systems only after explicit approval.
