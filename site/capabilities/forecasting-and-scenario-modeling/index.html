WORKFLOW DIAGRAM

How Outlook works.

Follow the numbered sequence. If evidence or access is missing, resolve it before advancing. Review the result before taking an external action.

  1. INPUT

    Baseline dataset · assumptions · unit economics · time horizon

  2. STEP 01

    Define drivers and units

  3. STEP 02

    Build best-base-worst cases

  4. STEP 03

    Stress-test sensitive inputs

  5. STEP 04

    Estimate confidence ranges where justified

  6. STEP 05

    Identify decisions triggered by thresholds

  7. REVIEW

    Clearly label projections as scenarios, not forecasts guaranteed to occur

  8. OUTPUT

    Scenario model · sensitivity table · assumptions log

Approval gate → Review the deliverables. If changes are needed, return to the relevant step. Publish, send, deploy or change external systems only after explicit approval.
