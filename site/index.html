ReverseReel

Turn short videos into searchable knowledge

Bring a permitted Reel, Short or local video. Keep timestamped Markdown notes and search them on your computer.

Install and use ReverseReel 
git clone https://github.com/saurabhmisal/power-chords.git
cd power-chords
npm run reversereel:install -- --agent codex --project ../my-project
npm run reversereel:ingest -- --source ./reel.mp4 --transcript ./reel.srt
npm run reversereel:search -- --query onboarding

Use codex, claude, cursor or gemini, or pass --dest /path/to/skills for other agents. Requires Node.js 24.x and ffmpeg/ffprobe. Supply captions or install local faster-whisper. Public URLs also need yt-dlp; optional OCR needs Tesseract.

Ask your agent: “Use ReverseReel on this video and find related notes.” Local terminal or stdio MCP access is required; browser-only chats need a connected runtime.

Previously Reel → Knowledge. Existing installs, knowledge:* commands and MCP tools continue to work. Your local knowledge base stays in place.
