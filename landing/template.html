01 / YOUR INPUT

Start with what you know.

“Partners manually re-enter failed order imports. The error message does not identify the failing row. Support cannot tell who owns the next step.”
Objective
Reduce manual rework when an import fails.
Constraints
Improve the current import flow; replacing the processing engine is outside this scope.
Still unknown
How often this happens, how long recovery takes, and which partner segment is most affected.
ILLUSTRATIVE SCENARIO
02 / A REVIEWABLE DOCUMENTDRAFT · REVIEW REQUIRED

Partner import recovery

Selected sections from the native workflow’s document structure.

Problem statement & supporting evidence

Provisional problem: Reduce manual rework when an import fails.

The supplied observations describe manual re-entry, unclear errors, and unclear ownership. Keep these observations traceable; confirm their frequency and impact with customers.

Requirements draft
  • Describe and validate the end-to-end current state.
  • Detect incomplete or invalid inputs before advancing.
  • Expose status, ownership, and actionable errors.
  • Capture completion and failure events.

These are draft hypotheses to validate, not approved engineering requirements.

Measurement & experiment plan

Primary outcome: successful completion rate, with its definition and baseline still to be agreed.

Guardrails: error rate, operator workload, and customer escalations. Establish the baseline, then agree a controlled rollout or holdout where feasible.

Review & next actions

Validate the problem and user segment with customers. Review scope with engineering and design. Assign ownership and agree the measurement and rollout decision.

A FEW THINGS WORTH KNOWING

Before you turn it up.

Does this work with Claude, Codex, or any other platform?

The instruction packs are Markdown. The installer supports project skill folders for Claude Code, Codex, Cursor, and Gemini CLI. Other hosts can use a custom skill directory or manually supplied instructions where supported. Execution depends on the host’s tools, context limits, and permissions; there is no universal automatic integration with every platform.

Do I need an API key or a paid model?

Native Workroom drafting uses deterministic templates and needs neither. An external agent or adapter may have its own subscription, credential, and runtime requirements. GitHub source inspection may encounter API rate limits.

Does a capability run an entire external application?

No. A capability pack provides instructions and metadata. Native assistance is scoped to implemented drafting workflows. Specialized operations such as OCR, audio generation, live research, or deployment require appropriate tools or reviewed adapters.

Where does my information go?

Local native generation runs on your machine. Hosted native generation sends input to the deployment server and saves recent documents in your browser. When using a third-party agent, its data-handling policies also apply. Download important documents; browser history does not sync across devices.

Is Power Chords open source?

First-party code and instruction packs use the MIT license. External projects retain their own authorship and licenses. Read the third-party notices before importing or redistributing external material.

What should I try first?

Choose PRD and specification writing if you have customer notes and a product problem. Choose the Integration Readiness workflow if you need to clarify interfaces, failure modes, testing, and release questions. Start with a contained task whose output you can review yourself.

How is a capability different from asking my agent a question?

A capability supplies a reusable task structure: required inputs, work steps, expected sections, and review criteria. You still provide the specific context and objective. Its value is making the approach and expected output explicit; result quality still depends on your evidence and the host agent.

What do “Native assistance” and “Adapter required” mean?

Native assistance covers implemented drafting, planning, and structured-analysis support. Adapter required means specialized execution needs a suitable tool or reviewed runtime. For example, instructions about transcription do not install a speech engine, and an integration plan does not connect to your production API.

Can my team customize the instructions?

Yes. First-party capability packs and code use the MIT license. Keep the license and attribution, then adapt the instructions, examples, and output contracts to your team. Review the separate licenses of third-party sources before importing or redistributing their material.
