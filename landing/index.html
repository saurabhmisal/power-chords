A FEW THINGS WORTH KNOWING

Before you turn it up.

Does this work with Claude, Codex, or any other platform?

The instruction packs are Markdown. The installer supports project skill folders for Claude Code, Codex, Cursor, and Gemini CLI. Other hosts can use a custom skill directory or manually supplied instructions where supported. Execution depends on the host’s tools, context limits, and permissions; there is no universal automatic integration with every platform.

Do I need an API key or a paid model?

Native Workroom drafting uses deterministic templates and needs neither. An external agent or adapter may have its own subscription, credential, and runtime requirements. GitHub source inspection may encounter API rate limits.

Does a capability run an entire external application?

No. A capability pack provides instructions and metadata. Native assistance is scoped to implemented drafting workflows. Specialized operations such as OCR, audio generation, live research, or deployment require appropriate tools or reviewed adapters.

Where does my information go?

Local native generation runs on your machine. Hosted native generation sends input to the deployment server and saves recent documents in your browser. When using a third-party agent, its data-handling policies also apply. Download important documents; browser history does not sync across devices.

Is Power Chords open source?

First-party code and instruction packs use the MIT license. External projects retain their own authorship and licenses. Read the third-party notices before importing or redistributing external material.
